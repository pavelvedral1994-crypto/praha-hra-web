# Stín nad Starým Městem

3D sledovací hra v prohlížeči v replice Prahy (Staré a Nové Město, Malá Strana, Hradčany, Smíchov, Vinohrady, Holešovice, Dejvice). Hraje se na telefonu i počítači:

**https://pavelvedral1994-crypto.github.io/praha-hra-web/**

Tohle repo obsahuje jen sestavenou hru (`index.html`, `app.js`, `worker.js`) a zpracovaná data (`data/`). Generuje ho skript `tools/web.sh` z hlavního (soukromého) repa; ruční změny tady se při dalším vydání přepíšou.
